# Οδηγός API Διαύγειας

## Τι είναι η Διαύγεια;

Η Διαύγεια είναι το επίσημο κυβερνητικό portal διαφάνειας της Ελλάδας. Δημοσιεύει όλες τις αποφάσεις δημόσιου τομέα, διατάγματα και νόμους προϋπολογισμού.

**URL**: `https://diavgeia.gov.gr/luminapi/opendata`

**Πρόσβαση**: Απόλυτα δωρεάν και δημόσια. Δεν χρειάζεται login ή API key.

---

## Endpoints API της Διαύγειας

Το API προσφέρει 3 κύρια endpoints για ανάγνωση δεδομένων:

### 1. Αναζήτηση Αποφάσεων (`/search/advanced`)

**Τι κάνει**: Αναζητά αποφάσεις σε ολόκληρη τη βάση δεδομένων της Διαύγειας.

**Επιλογές φιλτραρίσματος**:
- `query` — Αναζήτηση ελεύθερου κειμένου (ψάχνει τίτλο και πλήρες κείμενο της απόφασης)
- `organizationUid` — Φιλτράρ ανά οργανισμό που εξέδωσε την απόφαση
- `decisionTypeUid` — Φιλτράρ ανά τύπο απόφασης (π.χ. "Β.1.1" για διαγωνισμούς)
- `signerUid` — Φιλτράρ ανά πρόσωπο που υπέγραψε την απόφαση
- `fromDate` — Μόνο αποφάσεις που εκδόθηκαν από αυτή την ημερομηνία (μορφή YYYY-MM-DD)
- `toDate` — Μόνο αποφάσεις που εκδόθηκαν μέχρι αυτή την ημερομηνία (μορφή YYYY-MM-DD)
- `page` — Ποια σελίδα αποτελεσμάτων να επιστρέψει (0-based, default 0)
- `size` — Πόσα αποτελέσματα ανά σελίδα (default 10, max 100)

**Σημαντικός κανόνας**: Πρέπει να παρέχετε τουλάχιστον ένα φιλτρό. Το API απορρίπτει αναζητήσεις χωρίς κανένα φιλτρό.

**Ταξινόμηση**: Τα αποτελέσματα είναι πάντα ταξινομημένα από πιο πρόσφατα πρώτα. Δεν μπορείτε να αλλάξετε τη σειρά ταξινόμησης.

**Επιστρέφει**: Λίστα αποφάσεων που ταιριάζουν με τα φιλτρά σας, με πληροφορίες σελιδοποίησης.

---

### 2. Λήψη Μιας Απόφασης (`/decisions/{ada}`)

**Τι κάνει**: Ανακτά το πλήρες αρχείο για μια συγκεκριμένη απόφαση χρησιμοποιώντας τον κώδικα ADA.

**ADA**: Σημαίνει "Αριθμός Διαδικτυακής Ανάρτησης" — είναι μοναδικό ID που λαμβάνει κάθε απόφαση, όπως `6ΣΦ4ΩΞΧ-ΑΒΓ`.

**Επιστρέφει**: Πλήρες περιεχόμενο απόφασης, συμπεριλαμβανομένων:
- Τίτλος, ημερομηνία, οργανισμός, αριθμός πρωτοκόλλου
- Τύπος απόφασης και κατάσταση
- Σύνδεσμος προς το πλήρες PDF έγγραφο
- Πληροφορίες υπογράφοντος
- Θεματικές κατηγορίες
- Τυχόν συνημμένα (αν υπάρχουν)

---

### 3. Λήψη Οργανισμού (`/organizations/{uid}`)

**Τι κάνει**: Ανακτά μεταδεδομένα σχετικά με έναν ελληνικό οργανισμό δημόσιου τομέα.

**Είσοδος**: UID του οργανισμού (από το πεδίο `organizationId` μιας απόφασης)

**Επιστρέφει**: Λεπτομέρειες οργανισμού, συμπεριλαμβανομένων:
- Επίσημη ονομασία (στα Ελληνικά και Λατινικά)
- ΑΦΜ και νομική κατάσταση
- Ιστοσελίδα και contact email
- Πληροφορίες επόπτη
- Σχετικοί τομείς

---

## Τι εκθέτουμε στο MCP

Εμείς εκθέτουμε επί του παρόντος **2 από τα 3** API endpoints ως εργαλεία MCP. Ορίστε τι:

### MCP Tool 1: `diavgeia_search_decisions`

Αντιστοιχεί στο: Endpoint `/search/advanced` της Διαύγειας

**Τι κάνει στο MCP**: Αναζητά αποφάσεις με φιλτρά.

**Παράμετροι εισόδου που μπορείτε να περάσετε**:
- `query` — Όρος αναζήτησης ελεύθερου κειμένου
- `organizationUid` — Οργανισμός για φιλτράρισμα
- `decisionTypeUid` — Τύπος απόφασης για φιλτράρισμα
- `signerUid` — Υπογράφων για φιλτράρισμα
- `fromDate` — Ημερομηνία έναρξης (YYYY-MM-DD)
- `toDate` — Ημερομηνία λήξης (YYYY-MM-DD)
- `page` — Αριθμός σελίδας
- `size` — Αποτελέσματα ανά σελίδα

**Τι επιστρέφει στο MCP**: 
Μορφοποιημένη λίστα κειμένου που δείχνει:
- Πόσες συνολικές αποφάσεις αντιστοίχησαν
- Ποια σελίδα παρακολουθείτε
- Για κάθε απόφαση: κώδικας ADA, ημερομηνία, οργανισμός και τίτλος

**Παράδειγμα κλήσης**:
```json
{
  "organizationUid": "100037417",
  "fromDate": "2026-05-01",
  "size": 20
}
```

---

### MCP Tool 2: `diavgeia_get_decision`

Αντιστοιχεί στο: Endpoint `/decisions/{ada}` της Διαύγειας

**Τι κάνει στο MCP**: Ανακτά τις πλήρες λεπτομέρειες για μια συγκεκριμένη απόφαση.

**Είσοδος**: 
- `ada` — Ο κώδικας ADA της απόφασης (π.χ. "6ΣΦ4ΩΞΧ-ΑΒΓ")

**Τι επιστρέφει στο MCP**: 
Μορφοποιημένο κείμενο με:
- Κώδικα ADA
- Τίτλο
- ID οργανισμού
- Ημερομηνία έκδοσης
- Αριθμό πρωτοκόλλου
- Τύπο απόφασης
- Κατάσταση
- URL εγγράφου (σύνδεσμος προς το PDF)

**Παράδειγμα κλήσης**:
```json
{
  "ada": "6ΣΦ4ΩΞΧ-ΑΒΓ"
}
```

## Τι ΔΕΝ εκθέτουμε (Ακόμα)

### MCP Tool 3: `getOrganization` (ΔΕΝ ΕΚΤΕΘΕΙΜΕΝΟ)

Το API της Διαύγειας προσφέρει ένα τρίτο endpoint για ανάκτηση μεταδεδομένων οργανισμού (όνομα, ΑΦΜ, ιστοσελίδα κ.λπ.), αλλά δεν το τυλίγουμε ως εργαλείο MCP.

**Γιατί θα ήταν χρήσιμο**: Αν μια απόφαση δείχνει `organizationId: "100037417"`, δεν μπορείτε εύκολα να ανακαλύψετε ποιο είναι το πραγματικό όνομα αυτού του οργανισμού χωρίς ένα επιπλέον εργαλείο.

**Τρέχουσα κατάσταση**: Ο κώδικας υπάρχει στον βασικό πελάτη, αλλά δεν έχει εκτεθεί κανένα εργαλείο MCP ακόμα.

---

## Γνωστοί Περιορισμοί

1. **Χωρίς εργαλείο αναζήτησης οργανισμού** — Μπορείτε να φιλτράρετε ανά `organizationUid`, αλλά αν έχετε μόνο το όνομα, πρέπει να γνωρίζετε το UID.

2. **Χωρίς ανακάλυψη τύπου απόφασης** — Μπορείτε να φιλτράρετε ανά `decisionTypeUid`, αλλά δεν υπάρχει εργαλείο για να παραθέσει όλους τους τύπους αποφάσεων.

3. **Χωρίς ανακάλυψη υπογράφοντος** — Μπορείτε να φιλτράρετε ανά `signerUid`, αλλά δεν υπάρχει εργαλείο που παραθέτει διαθέσιμους υπογράφοντες.

4. **Η ταξινόμηση είναι σταθερή** — Τα αποτελέσματα έρχονται πάντα ταξινομημένα από πιο πρόσφατα πρώτα. Δεν μπορείτε να ταξινομήσετε κατά συνάφεια ή άλλες σειρές.

5. **Τα επιπλέον πεδία είναι άτυπα** — Κάθε τύπος απόφασης έχει το δικό του σύνολο προσαρμοσμένων πεδίων στο αντικείμενο `extraFieldValues`, αλλά δεν τα μοντελοποιούμε. Αυτά τα δεδομένα είναι διαθέσιμα αλλά μη σημειωμένα.

6. **Δεν υπάρχουν βοηθητικά προγράμματα σελιδοποίησης** — Το εργαλείο σας λέει το σύνολο και την τρέχουσα σελίδα, αλλά δεν κάνει αυτόματη λήψη όλων των σελίδων.

---

## Τυπική Ροή Εργασίας

1. **Αναζήτηση** χρησιμοποιώντας `diavgeia_search_decisions` με φιλτρά (π.χ. οργανισμός + εύρος ημερομηνιών).
2. **Επιλέξτε ένα αποτέλεσμα** από τη λίστα — πάρτε τον κώδικα ADA.
3. **Λήψη λεπτομερειών** χρησιμοποιώντας `diavgeia_get_decision` με αυτό το ADA.
4. **Χρήση των λεπτομερειών** — διαβάστε τον τίτλο, ελέγξτε το URL εγγράφου, σημειώστε τον υπογράφοντα.

---

## Περιεχόμενα API που Αξίζει να Ξέρετε

- **Ασυνέπεια ονοματοδοσίας**: Όταν αναζητάτε, χρησιμοποιείτε `organizationUid` και `decisionTypeUid` ως ονόματα πεδίων φιλτρού, αλλά το αντικείμενο απόφασης που λαμβάνετε ονομάζει αυτά `organizationId` και `decisionTypeId`. Αυτό είναι πραγματικό παράδοξο στο API της Διαύγειας.

- **Το ελεύθερο κείμενο πρέπει να είναι σε εισαγωγικά**: Πίσω από τα παρασκήνια, τυλίγουμε πάντα το `query` σας σε εισαγωγικά και το αποδιακτυπώνουμε ως αναζήτηση πεδίου Lucene (`content:"your query"`). Οι απλοί όροι απορρίπτονται από το API.

- **Max 100 αποτελέσματα ανά σελίδα**: Το API περιορίζει το μέγεθος σελίδας σε 100. Αν ζητήσετε 150 αποτελέσματα ταυτόχρονα, επιστρέφονται μόνο 100.

## Ταυτοποίηση

Δεν απαιτείται. Το API είναι εντελώς δημόσιο και ανοιχτό.

## Περιορισμός Ρυθμού

Δεν υπάρχει επίσημος περιορισμός ρυθμού τεκμηριωμένος, αλλά ισχύουν τυπικές καλές πρακτικές: μην το χτυπήσετε δυσκολά.
