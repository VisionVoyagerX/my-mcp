# Greek Gov Services — API Research

**Methodology**: Initial research (search-based) cross-checked each service against its official `.gov.gr`/`.gr` domain, official docs/PDFs, GitHub Swagger pages, and existing maintained SDKs. Confidence ratings initially based on search evidence (Google-indexed URLs, docs pages, etc.). **Liveness verification (2026-07-21, unrestricted network)**: All major endpoints and base domains tested via direct HTTP requests from external network. Results supersede prior search-based ratings.

**Latest update (2026-07-21)**: Deep-research workflow verified 11 claims via adversarial multi-agent fact-checking (3-vote consensus per claim) across official portals, GitHub org repos, EU open-data reports, and existing SDK implementations. Key findings: data.gov.gr auth model ambiguous (token vs. public query endpoint), Ktimatologio recommended as new Tier 1 candidate, HNMS weather service confirmed as no-public-API (portal/CMS only). See notes below.

**Live verification (2026-07-21, unrestricted network)**: Tested all Tier 1/2 base URLs and sample endpoints via direct HTTP requests. Results: data.gov.gr CKAN API live & working (200 OK), Diavgeia live but in maintenance mode, ΓΕΜΗ Swagger docs live (200 OK), Ergani II + sandbox live (currently in maintenance), Ktimatologio exists but 403-gated (auth/IP-restricted), Geodata.gov.gr times out (no response), e-prescription.gr domain does not resolve, myDATA sandbox URL (mydataapidev.aade.gr) returns 404 (endpoint may have moved), Monopigi.com does not resolve (unregistered domain — confirms user report). Detailed findings:

**ΚΗΜΔΗΣ Open Data API — live-verified and integrated into citizen-mcp (2026-08-08)**: Following the search-based discovery below, the API was re-verified with direct unauthenticated HTTP requests from this environment: `POST /request`, `/notice`, `/auction`, `/contract`, `/payment` (all 200 OK with real, current data — e.g. a live search returned 385,479 total request records), `GET /adamChain/{ref}` (successfully traced a real contract's full lifecycle: request → approved request → notice → award → contract), and `GET /{type}/attachment/{ref}` (200 OK, resolves to a real PDF). Only `GET /pde` could not be verified with a successful response — every ΠΔΕ number tried returned 400 (invalid), so its 200-response shape remains unconfirmed. Implemented as `packages/core/src/kimdis/` (client + zod types + 8 MCP tools: one search tool per lifecycle stage, `kimdis_get_adam_chain`, `kimdis_get_attachment`, `kimdis_lookup_pde`) and wired into `citizen-mcp`'s worker — no new secret or rate-limiter binding needed, since ΚΗΜΔΗΣ's documented 350 req/min cap is well above the worker's existing 30 req/min per-IP limiter. Confirmed working end-to-end via a running `wrangler dev` instance + real JSON-RPC tool calls (not just build/lint/typecheck).

**ΚΗΜΔΗΣ Open Data API discovered (2026-08-08, search-based)**: Researched at user request as a candidate addition to `citizen-mcp`. ΚΗΜΔΗΣ (Κεντρικό Ηλεκτρονικό Μητρώο Δημοσίων Συμβάσεων — the central public-contracts registry) launched a public, unauthenticated Open Data API in June 2025, documented at `https://cerpp.eprocurement.gov.gr/khmdhs-opendata/help` with a Swagger UI at `.../khmdhs-opendata/swagger-ui/index.html`. Distinct from ΕΣΗΔΗΣ (Εθνικό Σύστημα Ηλεκτρονικών Δημοσίων Συμβάσεων), which is the login-gated transactional tendering platform with no public read API of its own — the Open Data API lives under ΕΣΗΔΗΣ's domain but exposes ΚΗΜΔΗΣ registry data specifically. See the endpoint-detail section below (now updated with the live-verification note above).

**myDATA endpoint re-verification (2026-07-25, unrestricted network)**: The 2026-07-21 "sandbox 404" finding above was a false negative — it tested the sandbox host with the production `/myDATA` path prefix. Re-tested every one of the 11 ERP-user endpoints, unauthenticated, against both hosts: production `https://mydatapi.aade.gr/myDATA/<endpoint>` and dev sandbox `https://mydataapidev.aade.gr/<endpoint>` (no `/myDATA` prefix on the sandbox — confirmed against the official PDF's own worked dev-URL examples, which all point at `mydata-dev.azure-api.net/<endpoint>` with no prefix). Every endpoint on both hosts returned 401 (GET, missing subscription key) or 411 (POST, length required) — i.e. the route exists and enforces the expected method — never 404. A garbage subscription key produces 403 with an empty body, confirming request wiring (headers, method, path) is correct end-to-end; parameter names and request/response bodies remain unverified since the APIM gateway authenticates before evaluating either. See `packages/core/src/mydata/client.ts` for the endpoint-by-endpoint detail and the one remaining open question (`counterVatNumber` vs `receiverVatNumber`, worked around defensively by sending both).

**ΓΕΜΗ credentialed end-to-end verification (2026-08-04, unrestricted network, real approved `GEMI_API_KEY` from ΚΥ ΓΕΜΗ)**: All 9 client methods exercised against production with a real key: metadata endpoints (`legalTypes`, `companyStatuses`, `gemiOffices`), `GET /companies` (search by name/afm), `GET /companies/{arGemi}`, and `GET /companies/{arGemi}/documents`. All returned 200 with the shapes the client expects — after fixing two spec-vs-reality mismatches the credentialed test surfaced: the official Swagger spec declares `Company.arGemi` and the standalone `id` field on `legalTypes`/`companyStatuses`/`gemiOffices` metadata entries as integers, but production actually returns them as strings (nested ref `id`s like `Company.legalType.id` really are numbers, confirmed live — the inconsistency is real, not a client bug). Fixed in `packages/core/src/gemi/types.ts`; see inline comments there for the field-by-field detail. This is the first Tier 1/2 service in this repo verified with a real production round trip rather than spec-only or unauthenticated-probe verification.

## ΚΗΜΔΗΣ Open Data API — endpoint detail

Base URL: `https://cerpp.eprocurement.gov.gr/khmdhs-opendata`. No auth for reads (350 req/min rate limit, 429 past that). JSON responses (Accept header or `.json`). CC BY 4.0 licensed, metadata/files refresh every 24h. A separate write-side API (`/khmdhs-api/...`, Basic Auth, for contracting authorities publishing *into* the registry) exists but is out of scope for a read-only citizen MCP.

The five search endpoints below all represent sequential stages of the *same* procurement (request → notice → award → contract → payment), not independent categories — see `/adamChain` for stitching one procurement's records together.

| Endpoint | Method | Stage (Greek) | Returns |
| --- | --- | --- | --- |
| `/request` | POST | Αίτημα (Request) | Paginated search over the internal pre-tender request stage — an authority recording an intended purchase (CPV, estimated cost, budget linkage) before any public announcement. Filters: title, cpvItems, organizations, signer, dateFrom/To, totalCostFrom/To, isInitial/isApproved/isApproval. |
| `/request/attachment/{ref}` | GET | — | PDF for a specific request, by ΑΔΑΜ (`##REQ#########`). |
| `/notice` | POST | Πρόσκληση/Προκήρυξη/Διακήρυξη (Notice) | The public tender announcement — the stage visible live in ΕΣΗΔΗΣ for bidders. Adds procedureType, finalDateFrom/To (bid deadline), publicFundingRefNum. |
| `/notice/attachment/{ref}` | GET | — | PDF for a specific notice (`##PROC#########`). |
| `/auction` | POST | Ανάθεση (Award — endpoint name is a literal-translation artifact, not a bidding auction) | Who won: contractorName, vatNumber, estTotalCostFrom/To vs. totalCostFrom/To (estimated vs. final). |
| `/auction/attachment/{ref}` | GET | — | PDF for a specific award (`##AWRD#########`). |
| `/contract` | POST | Σύμβαση (Contract) | The signed contract formalizing the award — same contractor/cost filters as `/auction`. |
| `/contract/attachment/{ref}` | GET | — | PDF for a specific contract (`##SYMV#########`). |
| `/payment` | POST | Πληρωμή (Payment order) | Disbursements against a signed contract — a contract can have multiple payment orders over its life. |
| `/payment/attachment/{ref}` | GET | — | PDF for a specific payment order (`##PAY#########`). |
| `/pde` | GET | — | Look up ΑΔΑΜ codes by ΠΔΕ number (public investment programme funding reference). |
| `/adamChain/{ref}` | GET | — | Given any ΑΔΑΜ in a procurement's chain, returns every linked request/approvedRequest/notice/auction/contract/payment ΑΔΑΜ — traces the full lifecycle. |

## Competitive note (resolved — does not exist)

**Monopigi** (`monopigi.com`) — Domain does not resolve (ENOTFOUND, 2026-07-21). Previously searched results that mentioned "One API — All Greek Government Data," ~31M decisions, REST API + Python SDK, MCP support, etc., were SEO artifacts or cached/indexed pages without corresponding live domain. The detailed search results in prior research were likely false positives from aggressive keyword indexing or structured data markup without a live service. **Conclusion**: Not a real/live product. The domain either never existed, was unregistered after SEO setup, or was a pre-launch placeholder. Safe to exclude from competitive analysis.

## Recommended v1 MCP scope (highest value, lowest friction)

**Tier 1 (Blocked — requires clarification):** 4. **Geodata.gov.gr** — ✗ **Dropped from scope (2026-08-04)**, not deferred. **Tier 2 (Gated — highest business value but bring-your-own-creds):** 6. **AADE myDATA** — ✓ Main domain live; both production and sandbox hosts confirmed live with all 11 endpoints reachable (re-verified 2026-07-25, see myDATA row above).
